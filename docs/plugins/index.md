# Plugins

Plugins built with dsh-kit and reviewed for maintenance, documentation and safety.

## dsh-quicknote

Capture a note from the DSH composer, keep it out of the way, and manage the list on one page.

- **Documentation:** <https://dsh-kit.github.io/dsh-quicknote/>
- **Source:** <https://github.com/dsh-kit/dsh-quicknote>
- **Install:** desktop app → plugin page; CLI/web → `dsh plugin --profile web add dsh-quicknote`
- **Reference for:** composer capture, host JSON API, Agent tools, sidebar page, tests.

## Apply

The list is curated, not a marketplace. Read [CURATION.md](https://github.com/dsh-kit/dsh-kit/blob/main/CURATION.md)
and open a **Plugin application** issue with your repository, documentation URL and verification commands.
