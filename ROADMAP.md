# Roadmap

[中文](ROADMAP.zh.md)

dsh-kit is early. This page describes where the project is going, not a schedule and not a promise. Concrete work is
tracked in issues.

## What we are working on

- **Stability.** Keep generated plugins green across DSH release candidates, and publish the DSH range each
  release was tested against.
- **Coverage.** Support more plugin shapes than the current host + client template, and keep the default small.
- **Community.** Translations, examples and documentation that let someone contribute without reading the source.

## How to help

- Try the generator and report friction.
- Add a small example plugin built from the template.
- Translate a guide page.
- Improve the tests or the mount verification.

Open a **Roadmap task** issue with the outcome you want to check. Small pull requests are preferred.

## Not planned

- A plugin marketplace or hosting service.
- Patching or bundling DSH itself.
- Support for undocumented DSH APIs.
