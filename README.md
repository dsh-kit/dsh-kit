# dsh-kit

A maintainable baseline for DeepSeek Harness plugins.

`dsh-kit` generates a DSH plugin with the layout, build, type checking, tests, reproducible artifact and
agent-readable context already in place. Start with one command; keep the repository maintainable.

**Status:** pre-release, 0.1.0 · npm package `create-dsh-kit` · [Changelog](CHANGELOG.md) · [Roadmap](ROADMAP.md) · [中文](README.zh.md)

## Quick start

Requires Node 24+ (Node 26 LTS recommended) and pnpm 12; npm works as a fallback.

```bash
pnpm create dsh-kit my-plugin
cd my-plugin
pnpm install
pnpm verify
```

Then install it into a DSH profile:

```bash
dsh plugin --profile <profile> add link:$PWD
```

## What you get

- TypeScript + React 19 (TSX), strict.
- `src/host`, `src/client`, `src/shared`, with the ModuleLoader wrapper generated by the build.
- Tests for the host half and for client slot registration.
- `pnpm verify`: format, lint, type check, tests, build, pack.
- `AGENTS.md`, `llms.txt`, locale metadata, icon, CI and a release checklist.
