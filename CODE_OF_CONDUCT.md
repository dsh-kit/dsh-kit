# Code of conduct

This project follows the spirit of the Contributor Covenant.

- Be direct about the work, not about the person.
- Assume good faith; ask before assigning motive.
- Keep issues and pull requests on topic.
- Harassment, discrimination and personal attacks are not welcome.

Maintainers may edit or close threads that ignore these rules and may block repeat offenders. Report a concern
privately to the maintainers through GitHub; reports are handled confidentially.
